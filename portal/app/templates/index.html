Подключение

API совместим с OpenAI. Базовый адрес и ключ подставьте в свой клиент.

curl

curl {{ api_base }}/chat/completions \
  -H "Authorization: Bearer $LLM_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "{{ first_model }}", "messages": [{"role": "user", "content": "Привет"}]}'

Python

from openai import OpenAI

client = OpenAI(base_url="{{ api_base }}", api_key="sk-...")
answer = client.chat.completions.create(
    model="{{ first_model }}",
    messages=[{"role": "user", "content": "Привет"}],
)
print(answer.choices[0].message.content)

Ключ действует {{ policy.key_ttl_hours|duration }}. Продление — выпуск нового ключа; старый отзовите.
